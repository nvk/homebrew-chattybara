# homebrew-chattybara

Homebrew tap for chattybara.

## Install

```sh
brew tap nvk/chattybara https://github.com/nvk/homebrew-chattybara.git
brew install chattybara
chattybara --version
```

`chattybara` is the terminal chat client. The standalone modem engine `orca`
is distributed from Yoki's separate tap:

```sh
brew tap yokij/orca https://gitlab.com/yokij/homebrew-orca.git
brew install orca
```
